# 🍜 FoodAI - Flask Recipe Recommendation System

Web aplikasi rekomendasi resep makanan Indonesia menggunakan:

- Flask (Backend)
- Machine Learning
- Algoritma Apriori
- MySQL Database
- AI Chatbot makanan
- Login & Profile system

# Fitur
- Rekomendasi resep berdasarkan bahan
- Detail resep lengkap
- Login & Register user
- Profile & history search
- Chatbot makanan AI
- UI modern tema sage green

# Cara Run
```bash
pip install -r requirements.txt
python app.py
